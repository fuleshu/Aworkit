# Chat notice card: one surface for an interrupted reply and a stopped Run

The Chat Workspace has one compact notice card above the composer. It is the single surface for a condition that needs the user's attention or records that the Run stopped, and it is rendered by `ChatNoticeCard`.

- **Decision (warning accent)** — an interrupted reply that can continue or stop. Actions: Continue reply / Stop reply, with an inline stop confirmation. It is named "Interrupted reply" and narrates its progress politely.
- **Failure (danger accent)** — a terminal `execution.failed`. The card is announced as `role=alert` and keeps the failure title, body, Run details and Dismiss.

Both variants share one shell, one copy block and one action row, so a hard stop can never look like the old full-width warning bar. The former `.recovery-banner` / `.run-failure-banner` element and its CSS are removed; no Chat surface uses a full-width recovery banner. The card lives in `desktop/src/chat/ChatNoticeCard.tsx` with `desktop/src/chat/notice.css`.

## Not decided here

The card does not decide when a Run failed, what its title or body say, or whether a condition is resumable; those remain projection facts. It adds no second notice surface and does not change Run details or the evidence inspector.
